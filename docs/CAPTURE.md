# Capture Studio — 홍보 영상 촬영 가이드

Capture Studio는 영상 촬영 전용 화면입니다. Demo Mode 마을을 UI 없이 크게, 선명하게 보여줍니다.
Ambient Mode와는 완전히 별개이며, 열 때 만들고 닫으면 해제합니다. 저장되는 것은 없습니다.

## 먼저 알아둘 것: 왜 기존 녹화가 흐려 보였나

- 마을 아트는 **140 × 60 픽셀**입니다. 앱은 원래부터 정수 배율과 nearest 필터로 그리므로 앱 화면 자체는 흐리지 않습니다.
- 흐림의 원인은 녹화 이후에 있었습니다.
  - 넓은 화면에서 작은 영역을 잘라 **비정수 배율로 키움** (예: 4px 블록을 7.7배로).
  - **회색 바탕화면, 메뉴, 커서, 툴팁**이 마을 위나 옆에 함께 찍힘.
  - macOS 기본 녹화는 **가변 프레임레이트**라서 정지 구간과 끊김이 생김.
- 그리고 140 × 60이라는 아트 해상도 자체가 정보량의 한계입니다. 이번 버전은 아트도 보강했습니다(아래 "아트 변경").

Capture Studio는 이 문제들을 녹화 단계에서 없앱니다.

## 여는 방법

```bash
swift run OddlyTown --dev
```

메뉴 막대 집 아이콘 → **Developer → Capture Studio…**

- Demo Mode가 자동으로 켜지고(저장 안 됨) 첫 프리셋(Town)으로 시작합니다.
- Town Mode가 열려 있으면 닫힙니다. Ambient 마을은 Capture Studio가 열려 있는 동안 렌더링을 멈춥니다.
- 창은 테두리가 없습니다. 드래그해서 옮기고, **Esc**로 닫습니다.
- 마우스 포인터가 창 위에 있으면 숨겨집니다.
- 처음에는 단축키 도움말이 보입니다. **녹화 전에 H로 숨기세요.**

## 단축키

| 키 | 동작 |

| **L** | 레벨 1 → 2 → 3 순환 (새 시설은 0.8초 동안 나타남) |
| **D / S / N / M** | 낮 / 해질녘 / 밤 / 새벽 (3초 동안 조명 전환, 배경도 함께). **Shift**와 함께 누르면 즉시 전환 |
| **C** | 낮·밤 자동 순환 (5초 간격) |
| **E** | 계절 순환: 봄 → 여름 → 가을 → 겨울 (즉시 바뀜). 프리셋 1–5는 실제 달력 계절로 돌아감 |
| **R** | 주민 행동 순환: 산책 → 둘러보기 → 앉기 → 일하기 → 대화 → 귀가 → 독서 → 꽃 구경 → 축하 |
| **V** | 이벤트 순환: 길고양이 → 여행자 → 이웃 모임 |
| **O** | 장식 세트 순환 (즉시 바뀜, 컷 편집에 적합) |
| **G** | 활동 시설(공방·꽃밭·도서관·축제 깃발) 전체 켜기/끄기 |
| **Z** | 클로즈업 1× → 2× → 3× → 4× |
| **F** | 따라가기: 마을 → Mori → Pip → Juno → 마을 |
| **← → ↑ ↓** | 카메라를 1 아트 픽셀씩 이동 |
| **X** | 화면비 9:16 → 1:1 → 16:9 |
| **+ / −** | 배율 2× / 3× / 4× (화면에 들어가는 가장 큰 값으로 자동 조정) |
| **B** | 배경: 하늘(시간대 따라 변함) → 키 컬러(#FF00FF) → 스튜디오(어두운 남색) |
| **T** | DEMO 표시 켜기/끄기 |
| **Space** | 일시정지 |
| **H** | 도움말 표시/숨김 |
| **Esc** | 닫기 |

## 선명도 보장 방식

- **정수 배율만 씁니다.** 창 크기 = 캔버스(아트 픽셀) × 2/3/4 포인트. 클로즈업은 그 위에 1–4배를 더 곱합니다.
  - 예: Retina에서 3× + 줌 2 = 아트 픽셀 1개가 **12 × 12 기기 픽셀**.
  - 도움말 첫 줄에 "px per art px"와 녹화 해상도가 표시됩니다.
- 텍스처는 처음부터 `filteringMode = .nearest`입니다. 화면에서 추가 스케일링이 없습니다(장면 크기 = 뷰 크기).
- **카메라는 기기 픽셀 단위로 스냅합니다** (`CaptureLayout.worldOrigin`, `snapped`). 아트 픽셀 경계가 항상 기기 픽셀 경계에 놓이므로 이동 중에도 픽셀이 뭉개지거나 들쭉날쭉해지지 않습니다.
- 따라가기 카메라는 목표를 부드럽게 따라가지만, 그리는 위치는 매 프레임 스냅합니다. 확대/축소는 애니메이션하지 않고 **컷**으로 바뀝니다. 비정수 배율 중간 단계가 생기지 않게 하기 위해서입니다.
- 클로즈업에서도 카메라가 마을 바깥을 비추지 않습니다.

## 화면비와 녹화 해상도 (Retina 기준)

| 화면비 | 캔버스 (아트 px) | 2× | 3× | 4× |
|---|---|---|---|---|
| 9:16 | 144 × 256 | 576 × 1024 px | 864 × 1536 px | 1152 × 2048 px |
| 1:1 | 150 × 150 | 600 × 600 px | 900 × 900 px | 1200 × 1200 px |
| 16:9 | 160 × 90 | 640 × 360 px | 960 × 540 px | 1280 × 720 px |

14" MacBook Pro 화면에서 9:16은 3×까지 들어갑니다(4×는 높이가 넘침). 외장 모니터에서는 4×가 됩니다.

## 녹화 방법

**권장: OBS Studio (무료)**
- 소스: "윈도우 캡처" → *Oddly Town Capture Studio*, **커서 캡처 끄기**.
- 캔버스·출력 해상도 = 위 표의 녹화 해상도 (스케일링 없음).
- 30 fps 고정, 화질 높게(CRF 16–18 또는 "무손실에 가깝게").
- 이유: 고정 프레임레이트, 정확한 픽셀, 커서 없음.

**간단히: macOS ⇧⌘5 → "선택 부분 기록"**
- 창 테두리에 정확히 맞춰 선택합니다. macOS 녹화는 화면이 바뀔 때만 프레임을 기록하므로 편집에서 30 fps로 맞춰야 합니다.

## 편집에서 선명하게 쓰는 법 (1080 × 1920)

녹화 해상도(예: 864 × 1536)를 1080 × 1920에 맞추려고 1.25배처럼 **비정수로 키우면 다시 흐려집니다.** 두 가지 중 하나를 쓰세요.

1. **아트 픽셀 추출 (권장, oddly-reels가 쓰는 방식)**
   - 배경을 **B → 키 컬러(#FF00FF)**로 두고 녹화합니다.
   - 아트 픽셀 하나 = 도움말의 "px per art px" 블록입니다. 블록 중심을 샘플링하면 원본 아트(140 × 60)가 손실 없이 돌아옵니다.
   - 마젠타를 투명으로 바꾸고, Remotion에서 7× 같은 **정수 배율 + nearest**로 다시 키웁니다.
   - `oddly-reels/scripts/extract-ep01-frames.py`가 예시입니다(블록 크기와 원점만 바꾸면 됨).
2. **그대로 쓰기**
   - 9:16으로 녹화한 영상을 정수배로만 확대하거나(예: 576 × 1024 → 2배 1152 × 2048 후 크롭), nearest-neighbour로 스케일합니다.

## 장면별 촬영 가이드

각 장면은 **8–12초**씩 넉넉히 찍어 두면 편집에서 움직이는 구간을 고르기 쉽습니다. 녹화를 시작한 뒤 2초 기다렸다가 키를 누르세요(전환 전 상태를 남기기 위해).

| 장면 | 순서 | 팁 |
|---|---|---|
| **마을만 깔끔하게** | `1` → `H` | 9:16, 줌 1. 구름이 천천히 흐르고 주민이 돌아다닙니다. 썸네일·커버용으로 `Space`로 멈춘 프레임도 한 번 찍어 두세요. |
| **주민 행동** | `2` → `F`(Mori 따라가기) → `R`로 행동 바꾸기 | 줌 3에서 주민 한 명을 따라갑니다. 대화(`R` 여러 번)·축하는 표정이 커서 컷으로 쓰기 좋습니다. `V`로 길고양이/여행자를 부르면 짧은 이야기가 생깁니다. |
| **낮/밤** | `1` → 녹화 → `S` (3초) → `N` (3초) | 배경 하늘도 같이 바뀝니다. 밤에는 창문·문·가로등·랜턴 불빛이 땅에 비치고 반딧불이가 납니다. 밤 클로즈업은 `3` → `Z` 두 번 → 화살표로 집 쪽 이동. |
| **꾸미기** | `4` → `O` 반복 | 장식이 즉시 바뀌므로 음악 박자에 맞춰 컷 편집하기 좋습니다. 실제 꾸미기 UI가 필요하면 Town Mode 창을 따로 녹화하세요(Capture Studio는 UI를 보여주지 않습니다). |
| **성장** | `1` → `L` 눌러 Level 1로 → 녹화 → `L` → `L` | 새 시설이 0.8초 동안 올라옵니다. 이어서 `G`로 활동 시설(공방·꽃밭·도서관·축제 깃발)을 켜면 "다 자란 마을"이 됩니다. 마지막은 `5`. |

## 정직성 표시

- Capture Studio는 항상 Demo 상태입니다(저장 안 됨, 실제 진행과 무관).
- 기본으로 왼쪽 위에 **DEMO** 표시가 붙습니다. `T`로 끌 수 있지만, 끈 경우에는 영상에 "Demo Mode 화면 / 시간 압축" 같은 설명을 넣어 주세요.
- 성장 단계 전환은 실제로는 누적 2시간(Level 2), 6시간(Level 3)이 걸립니다.

## 아트 변경 (Ambient·Town Mode에도 적용)

- **주민이 더 또렷하게:**
  - 1px 외곽선과 눈을 추가했습니다(`TownArt.outlined`).
  - Pip의 셔츠 색(세이지)이 잔디와, Juno의 셔츠 색(모래)이 길과 거의 같아서 Pip은 청록, Juno는 자두색으로 바꿨습니다.
- **밤 조명:** 문 앞·가로등·랜턴 아래에 땅에 비치는 빛, 달무리, 반딧불이.
- **땅:** 길 가장자리의 닳은 자국, 잔디 하이라이트.
- 화면에서 확인한 것이 아니라 `scripts/render-art-preview.py`로 픽셀맵을 렌더링해 확인했습니다(`docs/art-preview.png`).
